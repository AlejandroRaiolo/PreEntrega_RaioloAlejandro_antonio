# 🍔 Don Burger

Sitio web de un emprendimiento de venta de hamburguesas artesanales. Es la pre-entrega del curso de **Front-End JavaScript** (Talento Tech).

## Páginas del sitio

| Página | Archivo | Contenido |
|---|---|---|
| Inicio | `index.html` | Portada con presentación del emprendimiento |
| Productos | `pages/productos.html` | Hamburguesas y papas fritas con foto y precio |
| Sucursales | `pages/sucursales.html` | Direcciones y horarios de cada local |
| Preguntas frecuentes | `pages/preguntas-frecuentes.html` | Preguntas y respuestas desplegables |
| Contacto | `pages/contacto.html` | Formulario de contacto |
| Sugerencias | `pages/sugerencias.html` | Formulario de sugerencias |

Todas las páginas se navegan desde un **menú desplegable** ubicado en el encabezado.

## Tecnologías utilizadas

- HTML5 (etiquetas semánticas: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 (archivo externo, Flexbox y media queries)
